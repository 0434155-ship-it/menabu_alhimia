# Между Нами Булочками

- [Основной каталог](index.html#catalog) — розница и предзаказ.
- [Праздничный каталог](preorder/index.html) — сезонная выпечка и заявка на выдачу.
- [Оптовый каталог](wholesale.html) — ассортимент, фасовки, состав и хранение. Оптовые цены запрашивают у менеджера.

Карточки используют фотографии из утверждённого архива. Оригинальные файлы хранятся в muka/selection, размеры и ссылки на публикации — в photo-sources.js. Ракурсы розничных карточек привязаны к конкретным вариантам в catalog-photos.js.

Источник оптового ассортимента и веса — вкладка «Весь ассортимент» прайса от 21.11.2026. Состав и хранение сверены с «Прайс-лист ОПТ 10.08». Отсутствующие и спорные условия хранения уточняются у менеджера. Оптовые цены выдаются по действующему приглашению.

## Кабинет оптового партнёра

Для локального запуска нужен Node.js 24. Выполните команду из корня репозитория:

    node partner/local.mjs

Страница для проверки: http://127.0.0.1:8765/wholesale.html#partner. Регистрация использует название компании, электронную почту и пароль. Данные сохраняются в локальной базе; каталог и история одного аккаунта не раскрывают записи другого. Заявка сохраняется в истории и затем её можно передать менеджеру. Регистрация не открывает закрытый прайс.

Локальное хранилище .partner-data исключено из Git. Переменные MENABU_PARTNER_PORT и MENABU_PARTNER_DATA позволяют отделить тестовую базу и порт. GitHub Pages обслуживает статические файлы. Для онлайн-регистрации нужно подключить сервер по тому же адресу маршрута /api/partner/ с постоянной базой и HTTPS. Локальный сервер слушает только 127.0.0.1. Подтверждение почты и сброс пароля пока отсутствуют.
